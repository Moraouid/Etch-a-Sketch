# Etch-a-Sketch

A simple browser-based drawing app inspired by the classic Etch-A-Sketch toy.

## Description

This project lets users draw on a grid by moving the mouse over cells. The grid size can be adjusted dynamically, allowing users to create larger or smaller pixel-art sketches.

## Features

- Interactive drawing grid
- Adjustable grid size
- Clean, retro-style UI
- Built with plain HTML, CSS, and JavaScript
- No external libraries or dependencies required

## Project Structure

- `index.html` — page structure
- `styles.css` — styling and layout
- `script.js` — grid generation and drawing behavior
